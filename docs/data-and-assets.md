# Data and assets

The repository includes one converted GarmentCodeData v2 garment, a canonical template, small initial-state pools, folding quality examples and converted Piper robot assets. GarmentCodeData is attributed under CC BY 4.0 in the README; the Piper upstream MIT notice is retained under third_party/agilex.

These numerical fixtures contain simulation states and mesh arrays. They are algorithm examples, not a public training-data release. Dataset and model download links are not yet available. Supply model bundles and LeRobot datasets explicitly through the documented command-line paths; private services are not required by the data inspection and offline scoring commands.

Data preparation, RGB export and training interfaces are documented in the README. The live RGB/GPU path requires the stated optional environment and assets; CPU tests do not establish that path or any paper success rate.
