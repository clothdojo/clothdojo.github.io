# RGB web delivery

Re-encoded from `../gallery86/rgb.mp4` and `../gallery86/rgb-mobile.mp4` with H.264, CRF 27, 850 kbit/s maximum rate, 1700 kbit buffer, 50-frame GOP and faststart. Original dimensions, 25 fps, frame counts (1200 / 640), composition and playback timing are retained. Desktop is 5.20 MB; mobile is 2.81 MB. Detailed texture is reduced by lossy re-encoding; source recordings remain in gallery86.

The homepage preloads only the active gallery card rather than both gallery videos, reducing competition with the opening film. Reduced-motion and data-saving behavior is retained.
